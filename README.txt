# Dinosaur Card Binder
App web instalable (PWA) para organizar una colección de monstruos de Tipo Dinosaurio de Yu-Gi-Oh!.

## Archivos para GitHub Pages
Sube el contenido de esta carpeta a la raíz del repositorio:
- index.html
- cards.json
- manifest.json
- sw.js
- carpeta assets/

Activa GitHub Pages desde Settings → Pages → Deploy from a branch → main → /(root).

## Instalar en Android
Abre la página publicada con Chrome, menú ⋮ → Instalar aplicación (o Añadir a pantalla principal). El icono del dinosaurio aparecerá en la pantalla inicial.

El progreso se guarda localmente en el navegador. Usa Descargar respaldo para conservar una copia.
